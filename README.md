## 🚀 Local Development

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start development server**:
   ```bash
   npm run dev
   ```

3. **Build production bundle**:
   ```bash
   npm run build
   ```

4. **Preview production build**:
   ```bash
   npm run preview
   ```

Push this repository to GitHub, go to [vercel.com](https://vercel.com), import the repository, and click **Deploy**. The `vercel.json` rewrite configuration handles all client-side routes out of the box.
